# Interview System - 音声対話型プロファイリングインタビューシステム

会話を通じて「一人の人間」を形成していくゲーミフィケーション要素付きインタビューシステム

## 概要

ユーザーとAIキャラクターが自然な会話を重ね、プロファイリングデータを収集しながら、
右ペインで「人間像」が徐々に形成されていく様子を可視化するインタラクティブシステムです。

**音声入力・音声読み上げ対応** で、より自然な対話体験を実現。
会話の途中でランダムに発生する**ミニイベント**で飽きさせません。

## 技術スタック

- **Backend**: Python 3.10+, Flask (ポート: 5001)
- **LLM**: LM Studio (http://localhost:1234/v1/chat/completions)
  - 推奨モデル: Qwen2.5:7b, Gemma2:9b
- **Frontend**: HTML/CSS/JavaScript (バニラJS)
- **音声**: Web Speech API (音声認識・音声合成)
- **データ保存**: JSON (data/ ディレクトリ)

## セットアップ

### 必要要件

- **Python 3.10以上**
- **LM Studio** (起動済み、ポート1234で待機)
- **モダンブラウザ** (Chrome/Edge推奨 - Web Speech API対応)
- **マイク** (音声入力を使用する場合)

### インストール

```bash
# 依存パッケージのインストール
pip install -r requirements.txt

# Flaskサーバーの起動
python backend/app.py
```

サーバーが起動すると `http://localhost:5001` でアクセス可能になります。

### 使い方

1. **LM Studio起動**: 推奨モデル（Qwen2.5:7bまたはGemma2:9b）をロード
2. **ブラウザで開く**: `http://localhost:5001`
3. **性別選択**: インタビュー開始時に性別を選択（キャラクターが決定）
4. **会話開始**:
   - **テキスト入力**: メッセージボックスに入力して送信
   - **音声入力**: 🎙️ボタンをクリックして話す（自動送信）
5. **音声読み上げ**: AIの返答が自動的に読み上げられます
6. **ランダムイベント**: 会話中にミニイベントが発生することがあります

## 機能

### 🎯 ゲーミフィケーション要素

#### 1. 人間形成ビジュアル（5段階）
会話を通じて収集したデータに応じて、右ペインの人型シルエットが成長します。
- **Stage 1**: 点（0-5データ）
- **Stage 2**: 骨格（6-15データ）
- **Stage 3**: 体（16-30データ）
- **Stage 4**: 詳細（31-50データ）
- **Stage 5**: 完成形（51データ以上）- オーラ付き

#### 2. バッジシステム（10種類）
特定の条件を満たすとバッジを獲得できます。
- 🎉 はじめの一歩（初めての会話）
- 🌟 多彩な人（5カテゴリー制覇）
- 🏆 コンプリート（全10カテゴリー制覇）
- 💬 おしゃべり（50回会話）
- 📚 ストーリーテラー（ライフストーリー10件）
- 🎨 趣味人（趣味データ10件）
- ❤️ 人間関係の達人（人間関係データ10件）
- 💡 学習者（学習データ10件）
- 🌈 深掘り（1カテゴリーに20件）
- 👤 人間完成（Stage 5到達）

#### 3. ランダムイベントシステム
**発動条件**: 3回以上会話後、10%の確率で発生

- **🎯 二択クイズ** (ボタン選択式)
  - 朝型派？夜型派？
  - インドア派？アウトドア派？
  - 計画的？即興的？
  - 一人が好き？みんなが好き？

- **💭 連想ゲーム** (自由記述)
  - 「夏」と聞いて思い浮かぶこと
  - 「家族」のエピソード
  - 「挑戦」の思い出
  - 「リラックス」する方法

- **📖 思い出話** (自由記述)
  - 子どもの頃の夢
  - 一番の思い出
  - 初めての経験
  - 大切な人

- **✨ 特別な質問** (自由記述)
  - 人生で一番大切なこと
  - 明日世界が終わるなら
  - 今の自分を一言で
  - 10年後の自分

#### 4. リアクション演出
AIがユーザーの発言に応じて3段階のビジュアルフィードバック（パーティクル演出）を表示します。

### 🎤 音声機能（Web Speech API）

#### 音声認識（音声入力）
- **ブラウザ標準のWeb Speech API使用**
- 🎙️ボタンをクリックして音声入力開始
- 認識結果が自動的に送信される
- 日本語認識対応

#### 音声合成（読み上げ）
- **AIの返答を自動読み上げ**
- キャラクターごとに音声設定が異なる
  - 美咲: 高めの声（pitch: 1.2）
  - 健太: 低めの声（pitch: 0.8）
  - あおい: 標準（pitch: 1.0）
- 絵文字を除去して読み上げ
- 🔊アイコンで読み上げ中を表示

### 📊 プロファイリングカテゴリー（10項目）

会話から自動的に以下のカテゴリーに情報を分類・保存します。

1. **基本プロフィール**: 名前、年齢、住所、職業など
2. **ライフストーリー**: 生い立ち、重要な出来事、思い出
3. **現在の生活**: 日常のルーティン、生活パターン
4. **健康・ライフスタイル**: 運動習慣、食生活、睡眠
5. **趣味・興味・娯楽**: 好きなこと、趣味、エンタメ
6. **学習・成長**: スキル習得、学び、目標
7. **人間関係・コミュニティ**: 家族、友人、コミュニティ
8. **情報収集・メディア**: ニュース、SNS、情報源
9. **経済・消費**: 買い物、消費行動、経済状況
10. **価値観・将来**: 大切にしていること、将来の展望

### 🎭 キャラクター

性別選択に応じて、適切なAIキャラクターが対応します。

- **美咲（みさき）**
  - 女性、20代後半、明るく聞き上手
  - 男性ユーザー向け
  - 表情: normal, happy, excited, thinking, surprised, concerned

- **健太（けんた）**
  - 男性、30代前半、落ち着いて知的
  - 女性ユーザー向け
  - 表情: normal, happy, excited, thinking, surprised, concerned

- **あおい**
  - 中性的、親しみやすい
  - その他のユーザー向け
  - 表情: normal, happy, excited, thinking, surprised, concerned

各キャラクター6種類の表情差分により、会話に応じた感情表現を実現。

## 🔍 開発メモ

### デバッグログ
バックエンドでは詳細なデバッグログが出力されます：
```
[Extraction] LM Studio response: ...    # データ抽出結果
[Extraction] Found X data points        # 抽出データ数
[Data] Saved: category - key: value     # 保存確認
```

### API エンドポイント
- `GET /api/health` - ヘルスチェック、LM Studio接続確認
- `GET /api/characters` - キャラクター一覧
- `POST /api/user/create` - ユーザー作成
- `POST /api/session/create` - セッション開始
- `POST /api/chat` - メッセージ送信
- `GET /api/badges` - バッジ一覧
- `GET /api/stages` - 人間形成ステージ一覧
- `GET /api/events` - ランダムイベント一覧

## 🛠️ トラブルシューティング

### LM Studioに接続できない
```
✗ LM Studio is NOT connected!
```
**解決策**:
1. LM Studioが起動しているか確認
2. `http://localhost:1234` でモデルがロードされているか確認
3. LM StudioのサーバーモードがONになっているか確認

### 音声入力が使えない（not-allowed エラー）
```
[Voice] Recognition error: not-allowed
```
**原因**:
1. **他のタブ/アプリがマイクを使用中** ← 最も多い原因
2. ブラウザでマイク許可が拒否されている
3. OSのシステム設定でマイク許可がない

**解決策**:
1. 他のタブ（Google Meet, Zoomなど）を閉じる
2. アドレスバーのマイクアイコンをクリック → 「許可」
3. macOS: システム環境設定 > セキュリティとプライバシー > マイク
4. Windows: 設定 > プライバシー > マイク

### 人間ビジュアルが成長しない
**確認事項**:
1. デバッグログで `[Data] Saved:` が出力されているか確認
2. 右ペインの「詳細ステータス」でカテゴリー別データ数を確認
3. 会話が具体的な内容になっているか（抽象的すぎるとデータ抽出されない）

### 音声読み上げが動かない
**確認事項**:
1. ブラウザが音声合成に対応しているか（Chrome/Edge推奨）
2. 🔇アイコンをクリックして音声合成を手動停止していないか
3. ブラウザコンソールでエラーが出ていないか確認
